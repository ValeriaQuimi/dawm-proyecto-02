# dawm-proyecto

# Un día en el Museo del Cacao

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una landing page para el Museo Nacional del Cacao de Guayaquil, con el propósito de dar a conocer su historia, importancia cultural y las experiencias que ofrece a sus visitantes.

La página web se desarrollará utilizando HTML5 y CSS3, a partir de la plantilla **Solid State**, disponible en [HTML5 UP](https://html5up.net/solid-state). Se personalizaron sus contenidos, imágenes, colores y estilos para adaptarlos a la temática del cacao y mejorar la visualización en diferentes dispositivos.

## Secciones de la página

La landing page está organizada en las siguientes secciones:

- **Inicio:** presentación del proyecto mediante una imagen principal y una frase introductoria.
- **Conoce:** información general sobre el Museo Nacional del Cacao.
- **Historia del cacao:** información sobre la producción, comercialización e importancia histórica del cacao en Guayaquil.
- **Importancia cultural y patrimonial:** explicación del valor del cacao como parte del patrimonio ecuatoriano.
- **¿Qué podemos encontrar?:** fotografías e información sobre las salas de exposición, piezas y recreaciones históricas.
- **Ubicación:** dirección del museo y mapa integrado mediante Google Maps.
- **Vive la experiencia:** galería fotográfica de los tipos de cacao y las salas que forman parte del recorrido.
- **Voces del Museo:** presentación de los resultados de una encuesta realizada a siete participantes.
- **Cuéntanos tu experiencia:** formulario para ingresar nombre, correo electrónico y opiniones.
- **Pie de página:** información de las autoras, enlaces a GitHub y LinkedIn y créditos del proyecto.

## Tecnologías utilizadas

- HTML5: estructura y organización del contenido.
- CSS3: diseño visual, estilos y adaptación de la página a diferentes dispositivos.
- JavaScript: funcionamiento del menú de navegación y componentes interactivos de la plantilla.
- CSS Grid: distribución adaptable de fotografías y tarjetas.
- Git: control de versiones del código fuente.
- GitHub: almacenamiento y colaboración en el proyecto.
- GitHub Pages: publicación del sitio web.

## Plantilla base

Se utilizó la plantilla **Solid State de HTML5 UP** como base para el desarrollo de la página.

Se conservaron elementos de su estructura original y se personalizó el diseño mediante el archivo `assets/css/paleta-cacao.css`, utilizando una paleta de tonos café y terracota inspirada en el cacao.

Plantilla original: https://html5up.net/solid-state
